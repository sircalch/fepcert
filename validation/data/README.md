# Data

- `fepplus_edges/`: per-edge FEP+ results (Bennett and cycle-closure-corrected ddG with their
  errors, and experimental ddG) of the public FEP+ benchmark: G. A. Ross et al., "The maximal and
  current accuracy of rigorous protein-ligand binding free energy calculations", Commun. Chem. 6,
  222 (2023); https://github.com/schrodinger/public_binding_free_energy_benchmark, commit a65d86b,
  directory 21_4_results/edge_predictions. MIT licence, copyright (c) 2023 Gregory A. Ross.
- The GROMACS data are those of the alchemtest package (`pip install alchemtest`), loaded by
  `benchmark_alchemtest.py`.
